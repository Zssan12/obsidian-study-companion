# 使用说明

安装入口：[Mac](installation/MAC-SETUP.md) · [Windows](installation/WINDOWS-SETUP.md)。先完成一条 Quick Ask 测试，再使用其他功能。

## 两种模式与独立追问

**普通模式**像普通 AI 聊天。切换文件不会改变当前普通对话；明确选中的文字可作为本次引用，不自动发送周围段落。

**学习模式**跟随当前 Markdown/PDF，每份资料有自己的对话和目录。打开文件只建立或恢复绑定，不调用模型；发送问题或点击梳理后才开始处理。生成途中切换资料，回答仍保存在原资料下。

**Quick Ask**是独立旁路。在笔记、PDF 文字或已保存回答中选中内容，点击 Quick Ask，检查引用和问题后发送。旁路不会自动继承整个主线，也不会自动合并回主线。关闭浮层会取消正在进行的请求；未发送旁路草稿没有持久保存保证。

## 输入区怎么用

- `自动 / 资料 / 直答`控制回答的资料使用方式；通常保留自动。直答不接受新的图片输入。
- 模型和推理强度可在输入区调整，先用默认；模型可用性取决于自己的服务权限。
- 输入 `/` 选择解释、举例、对比等模板，填入后可编辑，仍需手动发送。
- `＋` 添加文件或图片，也支持拖入文件、粘贴截图。每次最多三份附件，最多两张图片；发送前可以移除。
- 引用标签上的 × 只移除本次引用，不会抹除模型已经见过的历史。
- 右上角圆环显示本对话最近上报的上下文用量，各对话分别保存，重启可恢复；未上报时显示暂无数据。回答的调用消耗与上下文占用是两个不同指标。
- 主聊天草稿按资料保存，输入停顿后写入本地；突然退出可能丢失还没保存的输入。

## 目录与讲解

1. 学习模式打开 Markdown 或 PDF，点击梳理全文；Markdown 可选中文字后梳理选区。
2. 生成完成后展开学习目录，选择一个或多个主题，再开始讲解。
3. 目录保留已讲进度。修改原文不会自动替换现有目录；需要更新时主动点击重新梳理目录。成功后替换目录、重新计算进度；失败保留原目录。
4. 问题里可以明确指定 PDF 页码。页码指文件从 1 开始的实际页序，可能不同于页面印刷数字。

文字型 PDF 通常可直接读取。复杂图表、公式、多栏和扫描件可能需要额外识别；普通文字提取不保证完整理解图片。扫描页 OCR 需要自行安装 Tesseract 和相应语言包，然后设置本地 OCR；基础安装可先不启用。实验 PDF 图文证据选项有独立预算和适用范围，见 [PDF 说明](pdf-evidence-agent.md)。

## 离线英汉词典

选中英文词语，会展示内置词典中的中文释义和已有音标，不调用 AI。支持部分词形、短语和漏字候选；候选会标注“可能是”。不提供整句翻译；扫描 PDF 没有文字层时无法划词。取消选区、滚动原文或按 Esc 可关闭。

## 批量课件讲解（突击）

右上角闪电 → 选择或拖入多份 PDF → 调整顺序、填写可选学习目标 → 选择后端和模型 → 开始生成讲解。每份生成 Markdown，并生成总目录，保存到 `Study Companion 突击/本次任务/`。PPT/PPTX 请先导出 PDF。

默认读文字，无文字页补图；图表多时可选择逐页读取图表，会增加耗时和模型调用。单份上限 32 MB / 600 页，一次最多 20 份、总计 256 MB。可停止，已完成文件和完整批次保留；再次开始会创建新任务，不自动续写。原 PDF 不被覆盖，这个流程与聊天历史独立。

## 收藏与保存笔记

回答旁星标立即收藏，不调用模型。右上角收藏界面可搜索、分组、标记、取消收藏；选择已有笔记后先预览再确认合并。取消收藏不会删除回答。

“整理对话笔记”将当前范围的问答整理为精简笔记，点击开始才调用模型；确认预览才写入。普通聊天不会每问一次就在文件列表生成 Markdown。已导出笔记与聊天历史分别保存。

## 历史、清空与彻底删除

历史入口可搜索并恢复查看主线或 Quick Ask。右上角 `⋯ → 清空当前对话` 需确认：聊天移入已删除历史，开始新的 AI 上下文，清除当前用量并重置讲解进度；保留学习目录、收藏、资料和已导出笔记。

已删除区域提供 **恢复** 和 **彻底删除**。恢复让旧记录重新可读，不会自动把清空前的旧上下文合并进新对话。彻底删除需要额外确认，删除后不能从插件恢复；包含收藏的记录需先取消收藏。旧版 Markdown 历史须手动处理对应文件，不会批量删除。

这里的彻底删除作用于插件聊天记录，不会删除你自己的资料、已导出笔记、备份或 CLI / 模型服务方保存的日志。

## 检索与联网

笔记检索默认只限当前资料；可在设置扩展到同文件夹或整个仓库。普通解释不一定触发检索，明确要求找原文时按需读取，并显示工具活动及来源。PDF 页内检索有独立流程。

联网搜索按问题需要使用服务方能力，可在设置关闭。检索可能增加调用与等待；来源链接只帮助定位证据，不代表模型结论必然正确。详情见 [学习工具](learning-tools.md)。

## 数据在哪里

| 内容 | 默认位置 |
| --- | --- |
| 设置、学习状态、上下文用量、主聊天草稿 | `.obsidian/plugins/study-companion/data.json` |
| 新问答、引用、收藏等聊天历史 | 同目录 `history.json` |
| 旧版 Markdown 历史 | `Study Companion/`，继续兼容读取 |
| 导入附件 | `Study Companion Attachments/` |
| PDF 等资料缓存 | `Study Companion Cache/` |
| 批量生成的课件讲解 | `Study Companion 突击/` |

自定义配置目录时按实际目录定位。备份要包含隐藏的插件目录、自己的资料、附件及笔记。升级只替换三个运行文件；不要先卸载。模型会话还依赖本机 CLI，复制仓库不等于复制了 CLI 登录或原始会话。

遇到异常先看 [故障排查](installation/TROUBLESHOOTING.md)，不要先清空数据。
