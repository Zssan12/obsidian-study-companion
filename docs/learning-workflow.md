# 学习流程与验收

本轮新增手动验收：

1. 在右上角问答记录左侧打开全部收藏，展开含表格、代码块、列表和来源链接的回答，检查原生 Markdown 显示与跳转。
2. 导入真实 200–300 页 PDF，观察逐页进度；取消后重选同一文件应复用已缓存页。生成目录时检查首、中、末章节及无文字页提示。
3. 从目录讲解中后部主题，核对引用与原页；另问跨章节问题和全文总结，区分原文片段与分批摘要。
4. 对长对话整理笔记，生成中取消再执行，检查成功批次复用；完成后预览确认，重复整理不重复写入。
5. 主线、Quick Ask 分别追问，确认隔离；显式新开主线后不延续旧轮次要求。删除一条原记录后重新整理，不应从缓存恢复该记录。

## Persona（设计假设，未经用户访谈验证）

小林，正在准备技术面试的自学者，使用 Obsidian 阅读 PDF 和 Markdown。每次学习约半小时，遇到陌生概念会临时追问，希望保持主线进度。看到有用回答时想先留下，集中整理时再决定放进哪篇笔记。主要困难是频繁选择保存位置，以及看完解释后误以为自己已经掌握。

## User story

作为正在读资料的学习者，我希望顺手收藏有用问答、在独立侧线追问，并在学习结束后统一整理，让保存操作不打断阅读，也能保留问题的原始来源。

| 场景 | 用户操作 | 结果 |
| --- | --- | --- |
| 看到值得留下的回答 | 点回答旁星标 | 立即收藏完整问答记录，不选文件、不调用模型 |
| 解释仍不清楚 | 点“换个方式讲”或“举个例子” | 针对该回答继续讲解，不改变掌握状态或推进课程 |
| 临时追问概念 | 选择文字，打开 Quick Ask | 默认继承模型与强度，使用独立侧线 |
| 继续先前的追问 | 再次打开 Quick Ask | 沿用该资料当前侧线和自己的历史 |
| 开始另一条侧线 | 点“新开一条” | 建立独立侧线，原侧线留在历史 |
| 集中整理收藏 | 打开收藏，搜索、分类、勾选 | 按来源、标签、日期、模型浏览，可批量设置标签或取消收藏 |
| 把所选问答收入已有笔记 | 点“整理进笔记”，选目标、确认预览 | 合并完整问答，保留来源、已有编辑，并按问答身份去重 |
| 总结当前主线 | 点推理右侧“整理对话笔记”，确认范围后点“开始整理” | 独立请求生成尚未入笔记的摘要，确认后写入关联学习笔记 |

收藏是待整理的内容集合，笔记是明确整理后的产物。问答本身已经自动保存，因此不再需要“保存回答”入口。收藏批量合并保留全文；“整理对话笔记”才进行模型摘要。历史记录没有模型字段时显示“模型未记录”。

## Obsidian 手动验收

1. 完成一条主回答和一条 Quick Ask。各点星标，应立即变亮，没有文件选择；重载插件后，收藏中仍有完整问题、回答与来源。
2. 收藏界面分别按来源、标签、时间、模型分类；搜索回答里的词，勾选结果、批量设置标签，再取消收藏。原对话与已生成笔记应保留。
3. 选两条收藏，整理进同一普通笔记。预览前不写文件；确认后两条都存在。重复操作应去重，用户编辑应保留。预览期间修改或取消某条收藏，确认应提示重新选择。
4. 检查回答区没有“保存回答”“追加到笔记”“标记已理解”；“换个方式讲”和“举个例子”针对所点问答继续，不跳到下个课程主题。
5. 主线设置模型与强度后打开新 Quick Ask，应无后端弹窗，配置一致。回答后关闭，再打开并重载插件续问，应使用原侧线；主线历史不包含侧线问答。
6. 选择另一段文字再打开 Quick Ask，应沿用会话但使用新选区。点“新开一条”，应出现空侧线；原侧线可从历史继续。
7. 点击推理右侧“整理对话笔记”，应先显示来源、范围、保存位置和“开始整理”，不自动调用模型。点击开始后才生成；预览后取消不写笔记。确认保存只补充当前范围内尚未整理的主线问答；无新内容时显示笔记已是最新。

目前没有间隔复习提醒，也不根据一次阅读或点击判断掌握程度。自动化测试使用模拟后端与 DOM；真实解释质量、CLI 会话恢复及宿主视觉布局需要以上实机验收。
