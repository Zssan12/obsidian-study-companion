# 易用性迭代验收

目标：阅读资料时自然提问、继续阅读、之后找回对话。默认界面保持简洁，不靠增加按钮弥补状态不清。

## 用户实测反馈（2026-09-13）

用户反馈“来源与会话隔离”“输入与草稿”“阅读与布局”已测试，没有发现问题。记录为这三类的用户实测通过。找回对话、记录可编辑明确尚未测试，不能将猜测记为通过。本轮新增的发送区布局、普通模式选区和取消引用仍需重载后复测。

## 必须证明的使用行为

- 来源可信：发送前显示的资料与实际发送证据一致；切到新资料不显示其他资料的默认聊天；锁定后不会悄悄换资料。
- 输入可预期：普通模式不自动取笔记全文或光标段落；两个模式都能移除选区直接提问；模板只填入文本；中文输入法确认不误发；切换资料或生成结束不丢新草稿；常用操作可用键盘完成。
- 阅读不中断：流式更新保留历史消息 DOM、焦点和展开状态；向上滚动后不抢滚动位置；停止只在回答时出现。
- PDF 流程自然：已打开的 PDF 可以直接选择范围提问；常规短 PDF 不要求理解提取器；超限、扫描件和未识别图表明确可见；引用跳到正确页。
- 课件讲解：先生成带页码的主题目录，按用户选择逐节讲；支持调整顺序、跳过和单独选题，插问不推进，重载恢复当前位置，取消/失败/未保存不计入完成。
- 恢复可用：重开插件能找回来源和历史；错误后可以修正再问；保存失败不吞答案；编辑和移除的 Markdown 记录按磁盘状态更新。
- 视觉简洁：窄侧栏无横向溢出，模型和强度仍可识别，次要操作折叠，选区只显示前后各两个字符。

## 证据要求

单元与 jsdom 测试证明数据归属和事件行为；浏览器渲染检查证明布局；真实 Obsidian 与合成资料的操作证明宿主提取、CLI、引用回跳、取消和恢复。三者不能互相替代。既有 Node CLI 调用和旧截图不作为新版本通过证据。

主聊天窄侧栏和 PDF 弹窗已有浏览器布局证据，已收到前三类行为的用户实测反馈，历史与记录编辑仍待用户验证，本轮新增行为待复测。后台回答期间跨资料按钮/状态归属及异步焦点已有回归覆盖；历史搜索与 Quick Ask 原会话续聊也已有回归与浏览器布局证据；接下来需在宿主复验这些行为，不能将全目标标记完成。进度和执行结果记录在 validation.md。

下次宿主验证仅使用 `artifacts/Study Companion Test Vault` 的 Source A、Source B、PDF Synthetic。先重载当前安装包，按上述七项逐项操作并记下新请求结果。此前的 AbortSignal 错误记录不能作为新包失败证据，Node 成功请求不能作为宿主成功证据。缺少原生窗口控制时停止宿主部分；不重复禁用的 Obsidian CLI 或无权限 AppleScript 路径。

课件讲解的最短宿主复测路径：

1. 打开 `PDF Synthetic.pdf`，切到学习模式，点击“按主题讲解”并确认页码。只应生成目录；纯图形页应提示无文字，不编造其内容。
2. 点击“开始讲解”。只生成一节，结束后出现“继续”。输入“举个例子”，回答后主题位置应保持不变。
3. 展开目录，跳过一个未讲主题或调整顺序，再点击“继续”。应该只讲调整后的下一主题，不清空尚未发送的草稿。
4. 重载插件，再打开这份 PDF。当前主题、跳过和顺序应恢复，不自动发请求。切到 Source A 不应显示该 PDF 的目录。
5. 再次讲解时点击停止：未完成主题不计入已讲。保留页面报错文字及出现错误的具体步骤，不能仅以目录可见判定全流程通过。

学习笔记宿主复测（本轮仍待用户统一验收）：

1. 在合成资料的一条完整回答下点击“保存回答”，确认自动创建 `资料名/学习笔记.md` 并打开，全文、公式和表格保持原样；再次点击不重复。
2. 从输入区或课程目录工具栏点击“整理对话笔记”，确认只预览尚未保存问答的精简补充；修改一处正文并保存，应写入同一文件，原文和之前的手工编辑不变。
3. 再保存某条已经精简的回答全文，确认它升级为完整内容；若此前精简条目有手工修改，应保留该编辑版。
4. 再次完善，在没有新问答时应提示无需补充、不调用模型。生成期间保存其中一条全文，随后保存预览也不应覆盖全文。
5. 验证普通模式与 Quick Ask 手动保存、笔记重命名后的继续保存，以及两种模式 280–360px 侧栏布局。停止整理不写入文件。

缺少宿主控制时只记录这些未验项目，继续其他实现与检查，最后交由用户统一验收。
