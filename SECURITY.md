# Security

Do not post CLI credentials, private notes, complete vaults or unredacted plugin data in public issues. Reproduce problems with synthetic text and include only necessary error messages.

For suspected vulnerabilities, use the repository's private vulnerability reporting feature if enabled. If it is unavailable, ask the maintainer for a private reporting channel without publishing exploit details or private data. No response-time guarantee is currently offered.

The plugin treats documents, webpages and model output as untrusted. Read scope, request ownership, budgets and source identity are enforced by application code. Citation identity checks do not prove that a source supports a conclusion. Native shell and model-initiated note writes are unavailable.

Supported development target: the current release. Dependency checks run in CI. A passing dependency audit is not a security certification.
